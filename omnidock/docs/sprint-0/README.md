## Qué acordamos y qué cambió después

- **Metodología:** partimos en cascada; desde el 09/09 trabajamos en sprints.
- **Tablero:** íbamos a usar Planner; terminamos usando Jira.
- **Tecnologías:** Oracle, Java y Power BI se mantienen. Después sumamos Ionic para la app y el panel web.
- **Nube:** el despliegue se pensó en Azure; quedó en Oracle Cloud.
- **Hardware:** el hardware físico queda fuera del proyecto; se trabaja con un simulador.

Estos cambios están anotados en la matriz de control de cambios del ERS (anexo 5.7).
